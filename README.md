# 铁路票价模拟计算器

依据黄河铁路网《铁路标准票价计算方法》《铁路非标准票价计算方法》实现的中国铁路票价模拟计算网页（GitHub Pages 静态站，无构建、无依赖）。

## 功能

- **标准票价**：基价率 0.05861 元/km、递远递减、计费里程区间换算（区间锚点取两端均值）、客票/加快/卧铺/空调分项计算、新空调上浮 50%、快速/特快加快“先浮动、后舍入、再翻番”、保险先加后扣（五角起价）、软票费/候车室空调费/卧铺订票费、学生/儿童/伤残军人半价。
- **非标准票价**：900km 运价 f(900+d)−f(900) 及可配置上浮系数（1/2、7/20、35% 等，按“差价→非标准上浮→舍入→新空调上浮→快速翻番”顺序）、分段计价与卧铺起步折算（1/4、1/2、3/4）、乘数上浮链（平南线×3、广深先 ×1.5 再 ×1.3、海南卧铺 ×3）。
- **特殊线路**：达成线单位里程票价（不可递远递减、卧铺/空调 100km 起步）、青藏线席别加价（硬座 0 / 软座 0.09 / 硬卧 0.10 / 软卧 0.16 元/km，里程与国铁合并）。
- **折扣**：短途硬卧折扣 158%/170%、短途软卧折扣 258%/270%、新空调折扣（自定义上浮率）。
- **完整明细**：每一步换算、累加、舍入、上浮均展示计算式与中间值，可单步复制。

## 本地运行

纯静态文件，直接用浏览器打开 `index.html` 即可（ES Modules 需经 HTTP 访问，推荐本地起一个静态服务器）：

```powershell
# 任选其一
python -m http.server 8080
npx serve .
```

然后访问 http://localhost:8080 。

## 案例回归

- 浏览器：打开 `tests/test.html`。
- Node（可选，需本机安装 Node.js 18+）：

```powershell
npm test        # 即 node tests/node-check.mjs
```

标准案例 1–4 与非标准例 1、例 9 共 10 项严格通过；例 2、3、4、5、6、7、8、10 的文档基准值取自历史票价表（查表值），公式近似存在个位数偏差，测试页中以“≈ 参考偏差”标注。

## 部署到 GitHub Pages

1. 将本目录推送到 GitHub 仓库（根目录须含 `index.html` 与 `.nojekyll`）：

   ```powershell
   git init
   git add .
   git commit -m "railway fare simulator"
   git branch -M main
   git remote add origin https://github.com/<用户名>/<仓库名>.git
   git push -u origin main
   ```

2. 仓库 **Settings → Pages → Source** 选择 `main` 分支 / `(root)`，保存。
3. 访问 `https://<用户名>.github.io/<仓库名>/`。

## 目录结构

```
├── index.html            # 计算器页面
├── css/style.css         # 样式（中国铁路绿主题）
├── js/
│   ├── main.js           # 入口：参数收集 → 引擎 → 渲染
│   ├── ui/
│   │   ├── form.js       # 表单联动、运价区段编辑、快捷方案
│   │   └── detail.js     # 计算明细渲染
│   └── engine/
│       ├── util.js       # 舍入工具、基价常量、明细记录器
│       ├── mileage.js    # 计费里程换算、递远递减
│       ├── standard.js   # 国铁标准运价分段计算
│       ├── nonstandard.js# 900km 运价、乘数上浮
│       ├── special.js    # 达成线、青藏加价
│       ├── discount.js   # 短途卧铺折扣、半价
│       └── index.js      # calculate() 统一入口
└── tests/
    ├── test.html         # 浏览器案例回归页
    ├── cases.js          # 文档案例基准（共用）
    └── node-check.mjs    # Node 回归脚本
```

## 说明

- 计算结果为算法模拟，可能与部分地区、列车实际执行票价不同。
- 非标准运价案例中部分基准价（如卧铺起步价 44 元、票价表查表值）来自历史票价表，公式计算存在个位数偏差。
- 算法依据：黄河铁路网《铁路标准票价计算方法》《铁路非标准票价计算方法》。
